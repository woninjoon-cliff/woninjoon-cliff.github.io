클리닉 운영 ERP

2026.08 – 진행 중 · 기획·DB 설계·개발·배포 단독
문제
구매·재고·원가 데이터가 스프레드시트 6종에 흩어져 입력 누락과 마감 이후 소급 변경이 반복됐습니다.
만든 것
상담·시술·환자·구매·재고·통계·기준정보를 하나로 묶은 웹 ERP. 시술을 저장하면 재고·FIFO 원가·회원권 잔액이 자동으로 차감됩니다.
결과
업무 화면 30개를 실제 업무에 사용 중이며, 월 마감(재고·원가 집계)이 반나절에서 1시간 이내로 줄었습니다.

실제 운영 화면이라 금액·품목은 흐리게 처리했습니다.

설계 포인트

  • LOT·FIFO 원가 — 입고 LOT 순서대로 차감해 실제 단가로 사용 원가와 재고자산을 계산
  • 되짚을 수 있는 재고 — 모든 변동에 전후 재고를 기록해 기준일 재고를 재구성, 실사는 차이만 조정으로 반영
  • 병원 단위 격리 — 전 테이블 RLS, 채번·마감 검증은 DB 함수에서 처리

Apps Script · Cloudflare Workers · Supabase Edge Function(TypeScript) · PostgreSQL · Claude Code(AI 개발 도구)

마케팅·회원권 손익 시뮬레이터

2026.10 · 기획·계산 로직·화면·배포 단독
문제
마케팅 예산과 신규 회원권 가격을 엑셀로 수기 검토해 며칠씩 걸리고, 여러 안을 나란히 비교하기 어려웠습니다.
만든 것
마케팅: 채널별 DB 비용·CPA, 전환율, 상담단가로 월 예상 매출을 내고 과거 실적 추세·ROAS와 비교, 목표 매출까지 필요한 CPA·DB·전환율을 역산합니다. 회원권: 몬테카를로 500회로 기존 고객 매출 잠식분을 반영한 순증 이익·손실 확률·하위/상위 5% 구간을 계산합니다.
결과
시나리오별 손익분기점을 바로 확인하고, 복수 가격안 비교 결과를 최종 회원권 가격·구성 결정에 활용했습니다.

공개 데모 화면입니다. 숫자·병원명은 모두 연습용 임의 값입니다.
